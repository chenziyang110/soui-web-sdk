# 有限原生验证元数据

这些记录绑定实际执行和已闭合的独立审查：x64 选定源文件 DLL 重链、x64 正常 SDK 宿主诊断，以及 x64/x86 各 56 项公开原生单元测试。每份记录只包含结果字段、源码及产物身份、相对于仓库根目录的证据路径、字节数和 SHA-256，不复制源码、PE、DLL、工具实体或原始日志正文。完整产物清单通过身份和数量引用，不在这里重复巨大的散列列表；被引用的 out 文件是维护者本地证据，不随这些记录交付。

编译阶段的根进程退出 0、监督器退出 124，原通用通过判定（genericPassed）仍为 false，只按有限编译继续条件处理。运行诊断和全套 CTest 阶段均保留根进程、监督器退出 0 与 genericPassed=true 的真实结果。历史 DLL 链接失败、旧正常 SDK 关闭失败和记录日志的诊断失败继续保留为 false，不成为新成功证据。

选定重链保留旧 config 对象并加入新 PCH 创建对象，替换 Broker 对象；只建立所列源文件、对象和响应文件的有限绑定。其余旧对象来源、未知传递输入和完整编译器输入闭包尚未完成。正常 SDK 诊断实际完成受控文档及关闭、返回运行时关闭，并观察到已初始化模块保留；只有未初始化的 ABI 模式调用 FreeLibrary，未证明已初始化模块卸载。原生单元测试包含正常 22 个 SDK 源文件、36 个目标和 13 个 requestClose 源片段，但部分专用单元保留局部 getter 或启动边界接缝，不能升级为完整 DLL、分离引擎/UI 并发、GUI、目标系统矩阵或性能资格。
