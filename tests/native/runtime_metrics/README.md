These eleven cases call the normal public TaskService, PermissionStore, engine_thread, json_bridge and unmounted software adapter. The software lease and arithmetic boundary cases include the actual private production headers; they do not compile copied service implementations or enable TestKit macros. A Root-only wrapper can add the SDK then this directory to build the normal archive and executable once per architecture.

The cases cover actual 2-worker/32-inflight admission and duplicate/rejection accounting; cancellation before a handler; 128-subscription cleanup; 1024-entry terminal retention and eviction; two bearer aliases belonging to one scope; real renewal and unique revocation; FIFO callback reentry, stop/discard and join; the existing 256/128/1 lease lanes and exact-once release; optional GUI scalar reading without an owner-proof callback; default-off and owner-thread facade checks; saturation and invalid-clock handling. Blocked test callbacks are released before their production owners join, including assertion unwinding.

Each case is selected by one literal argv, has a 30-second CTest deadline and must exit naturally with the exact case receipt. Missing/unknown argv returns 2 with E_RUNTIME_METRICS_CASE. The normal native parent registers this directory. All three new test directories follow the SDK's fixed /MD and /U_DEBUG convention for both Debug and Release; the initial Debug CRT mismatch and its failure records are retained.

The eleven cases passed on x86/x64 in Debug/Release as part of the 116-case [finite integration](../../../verification/production-validation/0.5-runtime-capacity-2026-10-10/README.md). They do not prove mounted Host metrics, Modern runtime metrics, allocator totals, GUI input, resource trends or an eight-hour session. True Host/whole-process sampling and frozen thresholds are separate pending work.
