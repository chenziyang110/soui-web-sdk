# TaskStore 公开接口校准

这是独立安装消费者。先通过公开构建入口安装 SDK，再用已验证的同一
编译档位配置本目录，设置 `CMAKE_PREFIX_PATH` 为安装前缀。目标为
`SouiTaskStoreCalibration`，只链接 `Soui::Sdk` 与 `Soui::ActionJson`。

无参数运行显式使用未配置额度；传入一个十进制无符号字节数则重复同一
完整负载并执行该额度。`--default` 使用真正的两参数公开 Bridge 构造，
验证当前 SDK 默认额度；它不把默认数值作为显式参数传入。参数为 `0`
会拒绝正向存储请求，不能算校准通过。
应用内部总期限为五分钟，读取忙状态最多等待五秒，不自动重试被拒任务。

负载包括最大合法 Bridge 参数、kind/operationId/origin 边界、最大
进度/终态消息与结果、1,024 条历史、32 个同时在途任务、明确拒绝第
33 个任务，以及随后 64 次历史替换。输出 NDJSON 保留同一 Bridge 的
额度峰值与阶段状态、真实进程身份和采样区间。对象销毁后不读取旧快照。

外部运行控制器须绑定源码、安装 SDK 全文件、工具、真实编译链接、EXE
及其自有进程闭合记录。单独一份成功 JSON 不足以认定当前候选通过。
这是 Native 公开接口校准，不替代页面/GUI 负载、100 次重载、8 小时、
目标系统或全缓存预算；`productionDefaultQualified` 始终为 false。
