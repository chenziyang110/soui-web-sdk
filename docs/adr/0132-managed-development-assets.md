# ADR-0132：受管构建资源同步

## 背景

生成项目原先使用 copy_directory 更新 web，删除的源文件会残留在构建目录，开发运行与交付 staging 不一致。

## 决定

增加 SDK 构建工具及 CMake 入口，只同步应用拥有的可信前端资源。首次输出必须不存在；后续同步必须有相邻所有权清单且现有文件与清单一致。拒绝链接、特殊文件、越界/重叠、非预期额外或已修改文件，不接管任意目录。先有界读取/验证源和旧输出，再构建新副本并替换旧受管目录；失败不静默覆盖。清单放在 web 外，不增加可服务文件。工具不是对恶意并发文件系统的沙箱。

## 兼容与替代

已有项目不改写。新模板改用受管同步，旧 copy_directory 目录需用户选择新的构建目录，不自动迁移。正式 stage 仍 create-only。不采用盲目 rm -rf 或仅增量覆盖。开发运行必须停止后再同步；不承诺并发窗口可热更新或多进程同时构建。

## 验证

仅对删除传播、拒绝接管/修改/链接的高风险边界和已安装 SDK 生成项目入口作必要检查。完整回归与原生三平台运行另验。
