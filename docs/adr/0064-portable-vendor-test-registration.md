# ADR-0064：便携 SDK 与私有内核源码测试的注册边界

- 状态：proposed
- 日期：2026-10-11
- 决策者：维护者 / 评审人
- 关联：[Issue #76](https://github.com/chenziyang110/soui-web-sdk/issues/76)

## 背景

正常 SDK 源码身份包含 SDK、模板、Demo 和测试，未选择 Miniblink 私有实现源码。冻结的现代模板默认 ALL 构建已经完成四个 Web 包，却在配置无条件注册的 vendor_lifetime 时因缺少 wke.cpp 失败。此工作区不同于包含全部第三方源码的 Git source archive，也不同于生成业务项目安装的 SDK Core。

## 决定

SDK 自身测试保持默认开启。新增独立的 SOUI_BUILD_VENDOR_TESTS；首次配置中，SDK 测试开启且私有根路径存在时默认 ON，完全没有私有根的便携工作区默认 OFF。已有 CMake cache 保留显式选择。OFF 明确表示未注册、未验收内核源码回归。

ON 必须同时开启 SDK 测试，并要求全部 27 项实际私有源码存在且不是目录。根存在但不完整不能自动降为 OFF。原 54 个回归案例、真实源码字节校验、生成片段、断言和期限保持原有含义。SDK、Engine、Scope、metrics、公开内核头接口与应用测试不受该选项影响。

正式 Build/Test 入口显式请求 vendor ON，核对同一源码根、实际 CMake cache 和全部 54 个准确案例名称，再执行原 CTest。空注册、缺项、重复或额外内核案例均拒绝。私有 ABI 源对照与公开 Host 断言分开：公开断言始终执行，私有对照仅在实际 vendor 配置开启时执行，OFF 明确记录未验收。

## 备选方案

也可向筛选的便携工作区加入全部 27 项原私有源码。这会改变源交付范围，并要求处理原字节与换行归一化、许可及搬移验证；本次修复采用独立测试注册边界。完整底层源码包仍须保留其第三方源码承诺。

## 影响

不改变运行期 API、ABI、线程、权限或渲染行为。默认 ALL 可以在没有私有实现的 SDK 源码工作区构建；其结果只覆盖 SDK 和应用范围，不能替代 vendor 回归或完整内核重编。

## 迁移与回退

使用 fresh configure 验证新的默认值。完整开发树和正式验收显式开启 vendor 测试。曾缓存 ON 的工作区移除私有源码后应配置失败，调用者必须明确选择 OFF 并接受未验收状态。历史冻结源码、失败日志、已安装 SDK 和固定版本包保留原件。

## 验证

分别执行 x86/x64 便携默认 ALL 与完整私有输入的显式 ON 构建和测试。真实配置验证无源显式 ON、根存在但不完整、必需文件被目录替代、vendor ON 与 SDK tests OFF 的拒绝。核对公开测试仍存在以及全部 54 项原 vendor 测试的注册与实际执行。源码审查不等于这些验证已完成；GUI、资源、目标系统和发布资格仍由各自实际验收决定。
