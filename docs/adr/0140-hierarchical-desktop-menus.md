# ADR 0140：统一层级弹出菜单与托盘菜单

## 背景与决定

一份业务代码需要可嵌套的原生菜单，而不仅是扁平命令列表。统一 `menu_item` 尾部追加 `children`，保留原有聚合初始化；popup 与 tray 使用同一模型，不新增网页权限或系统菜单栏。

整个树最多 64 个节点，根节点深度为 1，最大深度 4；空根列表合法。非空 children 表示子菜单，必须有有效标题、空 id、checked=false。分隔符不能有 children，且 id/label 为空。叶命令 id 在整棵树内唯一。禁用祖先下的全部命令均不可派发，不仅依赖原生控件外观。

原生菜单使用各平台子菜单能力；所有叶命令保持当前菜单 revision 校验，旧菜单回调不能命中新菜单。Windows 子菜单成功挂接后由根菜单拥有，失败路径释放未挂接资源。

## 兼容性与替代方案

旧扁平菜单与叶 checked 行为不变；不增加另一套菜单 API，也不使用网页模拟原生菜单。空 popup 作为无命令菜单接受，后端不得因此产生命令。公开结构体布局变化要求源码重新构建，不承诺二进制 ABI 兼容。

## 验证边界

用聚焦契约验证深度、总数、唯一 id、父禁用和旧 revision；三平台分别实现原生映射。合成或 fake backend 通过不代表目标系统菜单交互通过，原生编译和 GUI 结果另记。
