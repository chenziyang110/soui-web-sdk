# 0.4.0-preview.1 预发布说明

日期：2026-10-08。渠道：preview。工程交付汇总 `sourceDeliveryVerified=true`，生产准入 `releaseReady=false`。本版交付现代后端与兼容基础；完整 0.4 目标仍以[执行清单](../roadmap/0.4.0.md)为准。

## 新能力

- 可选公共 `Soui::WebView2`：异步准备、明确的失败/取消结果、事件驱动 Bridge 消息泵、受控本地资源、安全导航限制及可重试关闭。兼容组件保持独立。
- React 19.3 / Vite 8.3 现代模板，`New-Project.ps1 -Profile modern` 生成仓库外独立项目。现代页面目标 Chrome 120，另需受支持系统和 WebView2 Runtime。兼容模板继续按 Chrome 49 构建。
- 原生系统、架构和 PE 探测及运行档位策略；独立原生诊断程序；Web API/CSS 能力报告。报告可用能力，不自动授权原生操作，也不把候选档位当作兼容认证。
- 旧系统帧计时从 2 ms 轮询改为下一帧期限唤醒，合并积压通知、停止后清理、恢复时不补过期帧。公共 Host 增加 `show()`，现代模板处理 DPI 变化。
- 固定 SDK 包内包含现代组件的源码、CMake 接入和开发包恢复工具；安装器在写文件前拒绝现代项目降级到缺少组件的旧 SDK。第三方授权文本在 Git 检出时保持原始字节。

设计见 [ADR-0016](../adr/0016-runtime-profiles-and-modern-backend.md)，用法见[现代后端](../modern-backend.md)。

## 交付与运行成本

交付固定源码 SDK、完整源码，以及 x86/x64 的兼容模板、Workbench 和现代模板运行包。另有带独立身份的 x86/x64 PE 软件内核候选，使用范围见[PE 候选说明](../pe-software-candidate.md)。每个归档附 SHA-256；仓库维持私有可见性。

现代模板 x64 ZIP 为 1,917,552 字节，解压载荷 4,495,602 字节；x86 ZIP 为 1,849,253 字节，解压载荷 4,218,818 字节。**这些数字不包含 WebView2 Runtime**；部署必须另行满足其运行时、系统和分发要求。运行包体积也不代表内存或完整离线开发环境成本。

完整工程现代前端构建需要 Node.js 22.12+；基础 SDK 与生成的兼容项目保留原有 Node.js 20.19+ 范围。MSVC v143、C++17、Windows SDK 10.0.19041.0 保持不变。Windows Git 检出完整历史证据时使用 `git -c core.longpaths=true clone <仓库地址>`。

## 尚未关闭

120/144 Hz 实机流畅度、输入到真实呈现、Electron 同负载对标、8 小时混合负载、GPU 资源与设备异常恢复、完整 Win7—Win11/PE 镜像矩阵、中文输入法/多屏/无障碍、签名及二进制授权审核仍需继续验证。当前主机为 75 Hz，不能据此宣称高刷目标或“所有系统完美适配”。

同版本 SDK 内容不可替换。兼容业务可回退到固定 `0.3.0-preview.10` 后重编；现代业务依赖的新组件不能静默降级。完整约束见[已知问题](../known-issues.md)。
