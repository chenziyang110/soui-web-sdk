# 发布前测试夹具与文档同步

完整 x64 Release 单元测试在汇总器测量分组夹具失败：新增前置检查使按总调用次数停止的夹具提前中止。改为在下一个明确阶段停止，仍断言六组测量及各自 LLVM 身份。后续分组又发现安装消费者夹具未提供生产读取器已要求的原始 observer context；补齐模型记录，生产身份校验未变。两项各九个定向用例和剩余公开 Node 测试组通过，原失败及后续原件均保留。

十一处 Web/测试依赖使用当前锁文件完成 npm 审计，均无已知漏洞。API/架构文档修正早期版本留下的可选 UIA、本地 Agent 和 WebView2 说明。内核许可检查单改为实际 0.5.0 双架构 DLL 的身份与构建来源，授权审核仍为未完成。

这批改动没有修改运行代码、构建观察器或原生编译输入。后续使用既有正式增量构建校验：重新核对历史真实观察与每个复用编译输入，冻结新候选并运行完整矩阵。上述测试和审计不代表整体发布资格。
