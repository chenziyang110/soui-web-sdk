# R40 匹配基线诊断源码快照

本目录保存19个冻结原文件的逐字节副本和相对路径清单，不含二进制、SDK、内核、日志或开发机操作驱动。原件的执行结果见[匹配输入诊断报告](../../../../docs/performance/sdk-preview4-matched-input-20261106.md)；新副本所在目录没有重新构建、运行或继承任何新产物资格。

`project/`是既有单次bootstrap消费者及有界原生/同步getter旁证，`page/`和`reader/`沿用v5不重叠64cell协议，`tests/`只覆盖预期SDK版本的读取边界。消费者通过显式 `SOUI_SYNC_HAS_BACKEND_FRAME_RATE_API` 编译开关区分0.6.0缺少的两个帧率覆盖接口；没有删除版本检查或以不存在的方法冒充成功。读取器只接受显式预期0.6.0或0.7.0-preview.4。

该工程还需要匹配的已安装SDK与原私有诊断头、标准编译接入及原冻结R39输入器，均不包含于此。不得把它当作普通SDK模板，或凭借本快照重新拼装载荷后沿用原资格。页面需要Host生成、受校验的配置；输入必须另行核对真实前台、held PID/birth、run、nonce/CRC和原期限后才可明确授权启动。本目录没有自动启动入口。

0.6.0私有trace-scope内核不等于发布内核；R40原目录64项严格诊断通过仍不构成测量税、噪声、物理输入/显示或性能收益通过。旧默认K0丢事件、精准请求点偏差和其他失败保持。源码清单不包含自身散列，避免循环引用；复制不运行测试或修改产品。
