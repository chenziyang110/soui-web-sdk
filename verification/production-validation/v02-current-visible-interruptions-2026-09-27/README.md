# 当前 V02 可见交互的外部负载中断样本

本目录保留四次未完成的尝试及其原始退出码、门禁、截图和测试驱动，共 111 份原始记录。它们与 [x64 完成的一轮短测](../v02-current-visible-x64-2026-09-27/README.md)分开判定，不能当作功能失败或通过。

- x64 `attempt4`：应用已启动，外部 `qemu-system-x86_64.exe` 随后出现；监督器只清理自己的应用，状态 `interrupted-external`，驱动退出 1。没有继续发送完整交互输入。
- x86 `attempt1`：启动前门禁发现外部 QEMU，应用没有启动，驱动退出 1。
- x86 `attempt2`：应用到达 V02 页面、接收外层滚轮并启动公共任务后，下一次输入门禁发现外部 `qemu-img.exe`，驱动只清理自己的应用，退出 1；尚未发送拼音、缩放或内层列表滚轮。该次监督器的 `native-nonzero` 来自驱动清理，不是自然关闭或无干扰的应用故障结论。
- x86 `attempt3`：应用再次启动、滚动至任务区并启动任务，真实拼音按键已发送；提交确认按键前外部 `qemu-system-x86_64.exe` 出现，驱动只清理自己的应用。没有记录到汉字提交、缩放、内层列表滚动或自然关闭；该中断不能用于下结论。

新的快速驱动版本仅修复成功后遗留的等待计时器；两个版本、x86 输入探针源码/二进制和构建日志均在 `raw/controls/`。`raw-manifest.json` 逐文件记录原件散列，`review.json` 仅总结可机械证明的范围。当前 x86 V02 完整交互及 Win7 SP1 x86 均未通过，`releaseReady=false`。
