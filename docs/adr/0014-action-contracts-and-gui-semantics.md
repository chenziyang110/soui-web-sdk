# ADR-0014：受权动作契约与可观察界面语义

日期：2026-10-03。状态：实施；preview功能，不构成全部Agent或生产支持。

## 决定

公共原生方法增加可选 `soui.action/1` 契约：标题、说明、输入与输出的有界JSON schema。一个注册入口保存契约、验证参数及成功结果，并沿用现有会话能力授权；`bridge.describe` 仅向有权调用该方法的会话返回契约。未声明契约的旧方法继续工作。schema仅实现明确公布的子集，未知关键字在注册时拒绝，不能假装支持完整JSON Schema。同步动作处理器必须有界；现有长任务继续使用公共task服务，本版不通过schema授予task.start额外权限。

宿主可在bootstrap前配置文档能力白名单；默认保持旧行为，配置后直接调用与发现均受同一原生白名单限制。网页提供的actor、手势或控制标志不能改变权限。白名单由C++应用配置，配置在首个bootstrap时冻结，导航只更新会话凭据。此机制是文档授权，不提供外部Agent身份认证或任意远程网页权限。

Web SDK提供受控界面的语义注册器：稳定ID、角色、名称、状态、动作和显式等待条件；查询与动作只针对应用明确注册的节点。所有动作通过应用注册的异步处理器，支持有界等待、忙碌/禁用检查、销毁取消等待和错误传播；不通过任意选择器执行脚本，不伪造真实用户手势。它可以绑定公共原生动作契约，并供人类界面与Agent客户端调用同一业务动作。能力清单可转换为工具定义，执行仍由原生校验与授权最终裁定。

## 备选、迁移与验证

不把条件编译的Miniblink测试DOM接口作为公共SDK，也不新增Demo依赖。采用可选择的注册器而非全页面自动暴露，避免把未知DOM及输入误当成允许的动作。此轮不建立公网Agent服务，不改变旧连接行为或默认渲染器；新API为源码SDK新增能力，版本增加。

验证原生注册拒绝/输入输出校验/授权分页/白名单不可绕过、Web契约与工具定义校验、界面快照/动作/禁用/超时/销毁，以及安装后两种真实渲染器上的最小业务流程。UIA、独立Agent主体、完整长任务工具协议、真实输入和跨平台继续独立验收。正式发布前完整构建/启动/包清单核验，预发布保持 `releaseReady=false`。
