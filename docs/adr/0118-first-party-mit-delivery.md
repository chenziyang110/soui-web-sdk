# ADR-0118：首方 MIT 许可随 SDK 和应用交付

- 状态：accepted（维护者于 2026-10-16 明确选择 MIT）
- 关联：Issue #39

## 决定

首方 SDK、模板、Demo 和维护工具采用根目录 LICENSE.md 的 MIT 许可。第三方文件保留各自版权和许可，MIT 不覆盖或替换这些条款。历史归档、第三方源码内的许可证和已发布 0.5.0 包保持原字节；新的交付身份为 0.5.1-preview.1。

LICENSE.md 纳入 SDK 管理文件、构建输入身份、CMake 安装的 share/SouiSdk，以及应用 resources/legal。部署前验证该文件存在，缺失即失败并保留旧资源。许可内容变化使旧构建身份失效；安装器继续拒绝同版本不同内容。

所有首方 SDK 包同步为 0.5.1-preview.1，独立 CMake 消费者保持 EXACT 并改为 0.5.1。React/Vue 绑定新增该版本组合的预发行 peer 范围，继续拒绝未选择的 0.5.2 预发行和 0.6；不改变运行时 API 或行为。

## 备选与兼容性

仅更新仓库首页会让安装包和独立应用丢失许可，因此不采用。保留原许可证的第三方内容不重新授权。应用自己的业务代码不会因使用 SDK 自动被改成 MIT。旧包仍按其清单校验，回退仍使用完整旧版本。

## 验证与边界

验证源包、安装后 SDK 和运行资源的许可证原字节，缺文件拒绝、源身份变化和升级回退。当前内核链接映射及上游条款另行记录。维护者选择首方 MIT 不等于第三方二进制全部授权审阅完成，也不关闭真实桌面、长测或生产资格门槛。
