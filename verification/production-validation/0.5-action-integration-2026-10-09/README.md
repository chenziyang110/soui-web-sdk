# 0.5 动作生成与主线整合

`index.json` 固定 632 个原始文件的字节与散列。实际整合基于主线基础切片，版本为 `0.5.0-preview.1`；尚未冻结或发布。

x64 完整 Release（含 WebView2）和 x86 SDK-only Release 均实际编译并安装。安装前缀移至仓库外后，两架构独立动作消费者按 v143/Windows SDK 10.0.19041.0 编译并真实运行；已重建的 SDK 网页输出完成 80 项动作、GUI 核心及客户端相关回归。四个编译任务的根进程都返回 0，但存在编译器尾进程，通用监督仍为失败并受控清理；没有使用或追认编译器尾进程例外。

首次私有语法检查命令缺少参数前的横杠，失败原件保留。后续只修正检查命令，两个标准 PowerShell 入口成功解析，进程组自然清空。独立审查还发现缺少动作源时旧构建 hook 跳过受管应用：真实 PowerShell AST 和 actiongen CLI 的旧 RED、新 GREEN 各 13 个分支验证了修复，全部夹具字节不变；旧无效夹具记录仍保留，不能作为通过证据。

三个源码身份分别绑定原编译、构建 hook 修复及验证收集入口接入。后两次只更改工具，不更改原生与网页输入；本记录没有声称重新编译最终工具身份或认证最终候选。六份现用前端/验证锁文件的实际 npm audit 均退出 0、报告 0 个漏洞。

原始脚本与源夹具以 inert snapshot 保存；编译二进制和安装库仍为本地验证载荷，本目录保存其身份与消费者工程证据。本次没有完成 GUI 流程、目标系统、性能、长测、完整固定包或正式发布验收，`releaseReady=false`。
