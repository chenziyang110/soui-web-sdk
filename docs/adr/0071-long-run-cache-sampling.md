# ADR-0071：长期运行中的命名缓存采样

状态：accepted

日期：2026-10-13

ADR-0070 的显式请求接口和可选 Acceptance App 参数已经定义，原公开八小时入口仍只传六个场景参数，无法取得新增观测。尚未执行本版本的实际八小时验收，现固定策略需要在执行前声明采样行为。

公开 `run-long-mixed` 和 `run-long-session` 沿原控制器、原八小时场景与原 Owned 期限执行，额外明确传入 `--cache-observation=1`。固定策略修订为 `0.5.0-m0-named-cache-sampling-v1`，请求范围记录 `named-process-cache-scalars`；普通运行、100 次重载资源入口和四种 1,000 次循环入口保留原参数，范围记录不请求此数据。真实时长、循环、场景步骤、采样数量、进程预算及所有原验收指标不变。

运行观察重新核对完整原始 argv 与当前冻结策略。命名缓存数据分析复用 ADR-0070 的 DTO 解析，绑定已核对的加载载荷文件、Owned PID/creation 和捕获时钟。所有缺失、非法和部分观测显式计数；数据缺失不补零，非法记录不丢弃。同一 `sampleQpc` 的完成副本只记为重复数据；新完成数必须使用更晚的原生采样时间且不是退休副本。记录原采样年龄和尾部退休副本，不把界面读取时间当作采样时间。

此切片只接通采集和数据描述。`cacheBudget`、资源与完整八小时资格仍受独立门约束，新增 DTO 数据不能单独授予任何资源通过结论。现有未关闭的资源、缓存限额与长期运行事项保持未验证，后续根据真实载荷和实际数据验证。新范围不能用于复述旧策略的历史运行；固定历史报告和失败证据保持原字节。

源代码数据回归覆盖两种八小时 argv、四种普通长循环参数、重复/退休副本、新采样计数、缺失、部分、错误身份与回退时钟；原长期策略与监督边界回归继续执行。实际 Native 编译与八小时运行尚未执行。选择采样优先于继续缺少观测；沿原入口优先于新增一套控制器。
