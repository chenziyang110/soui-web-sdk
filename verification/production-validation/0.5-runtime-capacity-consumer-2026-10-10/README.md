# Current runtime capacity: installed consumer evidence

This archive preserves four current-host Debug/Release x64/Win32 installed-consumer runs from ctconsumer-0f3dc37c-*. All 16 Owned stages (12 install/configure/build and four runtime stages) actually finished with root 0 / supervisor 0, whole-Job natural closure and no forced cleanup. No compiler-tail exception was used. Each installation contained exactly 50 files and 34 public SDK headers; the consumer compiled from tests/package-consumer/main.cpp, read the installed public bridge header and linked the corresponding installed archive through the generated imported SDK target.

The runtime smoke constructs the public software Bridge, enables directory, clipboard and window services, and processes a JSON input. It is finite current-host verification. The installed ActionJson header and exported include target are bound in the records; the actual consumer translation unit did not directly read the ActionJson header. These results do not establish GUI/Host/Modern behavior, resource or long-running stability, Win7/PE compatibility, complete toolchain provenance or release qualification.

evidence-map.json locates every configuration and all 16 real PID / decimal-string FILETIME stage identities. copy-index.json maps every raw attachment to its original absolute path, byte length and SHA-256. Every copy was hashed before and after copying and the original remained unchanged. Original JSON paths and values are deliberately preserved; portable archive-relative attachment paths are provided by the indexes rather than rewriting those records.

raw/source-wrapper retains the sealed wrapper, plans and deltas as inert attachments; raw/consumer-source retains the actual two consumer source inputs. raw/current retains results, complete final Owned records and stdio, project/cache/export text and target CL/LINK tracking. raw/root-review/review.json.raw is the independent Root actual audit. upstream-input-index.json preserves original producer, installed-file, binary and tool hash references. Executables, archives, objects, installed-header duplicates and compiler caches are not copied.

The original four capconsumer-0f35213c-* configure failures remain failed: roots returned 0 but their supervisors returned 124 after forced owned-tail cleanup; build/runtime did not run. Four ctconsumer-0bea1a0f-* attempts failed before a configure subject started because the old supervisor rejected an option. Absent configure ready/raw records are not invented. Their results, prep summaries and available raw records are retained under raw/historical. The new runs do not change those failures.

All control attachments use .inert or .raw names. The local .gitattributes disables line-ending and ident conversion for exact-byte storage; no raw package or attributes file becomes active. manifest.json uses literal Ordinal membership and hashes every member other than itself. The archive author only read and copied files; no Native, Node, helper, compiler, VM or Git operation was executed, and nothing was staged or committed.
