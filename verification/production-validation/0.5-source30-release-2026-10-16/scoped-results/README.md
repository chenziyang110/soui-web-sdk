# 0.5.0 本次限定范围结果

本目录记录 2026-10-16 发布验证的实际结果。两架构四配置构建、每架构 208 项 Release 原生回归、当前安装 SDK 的独立消费者，以及六个应用 ZIP 的八次解压启动均通过。Modern 的本机 100 Hz 主屏 S05 样本持续 120 秒，页面 requestAnimationFrame 中位节拍约 100.00 Hz。

`RELEASE-FACTS.json` 汇总实际范围与限制；`INDEX.json` 将保留文件映射到原路径、字节数和 SHA-256。大于 1 MiB 的文件采用 gzip，解压后与原记录逐字节一致。原构建清单与最终发布清单分开保留，文档整理不会被当作另一批构建结果。

本归档不是完整独立构建证明：原始工具观察流、部分运行输入和完整构建目录仍位于外部保留位置。长测、完整对比、生产资格与授权审核未完成，`releaseReady=false`。严格桌面截图采样因累计帧数大于一而失败，本轮只报告实际页面调度；该失败及旧 UIA 焦点失败、资源部署失败和增量资源记录失败均保留，后续通过不改写旧结果。

资源发布修复的红/绿回归及原失败见[相邻记录](../resource-publication-fix/FIX-REGRESSION.json)。完整说明见[0.5.0 发布说明](../../../../docs/releases/0.5.0.md)。
