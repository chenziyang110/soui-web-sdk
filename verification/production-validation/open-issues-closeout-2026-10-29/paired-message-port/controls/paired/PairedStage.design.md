The old installed SDK has 46 public headers in each architecture; all installed files and the actual library/version header are pinned in `PairedPreparation.actual.json`. The eventual four arms must be `x64-baseline`, `x64-candidate`, `x86-baseline`, `x86-candidate`, in that order. Each architecture must use the same fresh EXE, eight-file consumer-source snapshot, installed SDK, six Web output files deployed into three windows, and original runtime/CRT files in its two arms. The previous two current-0.6.0 SDK consumer runs cannot supply these EXE identities or stand in for any paired arm.
