# ADR-0012：渲染边界与公共能力发现

日期：2026-10-02。状态：接受实施，preview；不授予生产准入。

## 背景

宿主通过 `webview_host_adapter` 注入适配器，但常规操作仍向下转换到 Miniblink；其他适配器可能收到没有实际执行的成功结果。Web 客户端的类型表也不能证明原生方法已经注册。需要为多后端与 Agent 使用建立可验证的边界。

## 决定

1. 提取不依赖 Miniblink 实现的宿主配置、结果及适配器接口。宿主常规生命周期、尺寸、焦点、消息、就绪状态通过虚接口转发；保留现有 Miniblink 接入与受控本地资源规则。尚未实现的可选操作明确返回不支持，不能假成功。此步不声明已有第二个生产渲染后端。
2. `json_bridge` 增加经现有 session/origin/token 权限检查的 `bridge.describe`。按方法名稳定排序并分页，只返回当前会话有权访问的已注册方法及其 capability；不返回凭据，不授予权限，不调用业务方法。
3. 发现协议使用 `soui.capabilities/1`，返回 `sdkVersion`、`methods: [{name, capability}]`、`nextCursor`。请求只接受可选非负整数 `cursor` 和 1–64 的整数 `limit`，默认 32。游标针对 bootstrap 后冻结的注册表。发现只证明注册和当前授权，不能证明窗口、手势、设备或业务前置条件满足。
4. TypeScript 提供类型化发现与结果校验，错误显式传播；旧宿主不支持发现时不猜测能力。发现不是完整业务 schema，也不是公开远程 Agent 服务。注册方法名与已有可调用规则对齐，权限名限制为1–512 UTF-8字节；分页计入JSON转义及完整响应预算，必要时缩页但保证前进。普通响应超过64 KiB时返回 `E_LIMIT_MESSAGE_SIZE`。
5. 增加独立适配器与真实 Bridge 契约测试，并通过原生模板验证现有路径。正式 WebView2、界面语义树、领域数据通道仍须后续独立实施与验收。

## 兼容与迁移

保持现有 SOUI/Miniblink 默认、Chrome 49 构建目标、线程与运行库退出规则。新增通用接口不提高 Windows 或工具链下限。既有方法与权限保持原行为。自定义适配器需要实现其声称支持的操作；调用未实现操作得到明确错误。发布包内容变化使用新的 preview 版本，旧包与旧证据保留其身份。

## 备选与取舍

直接更换内核会把接口迁移、部署与渲染回归混在一起；仅增加静态能力列表会把类型声明误当成真实支持。本次先实现真实转发与受权发现，再通过第二后端验证更完整的架构。

## 验证与回退

原生测试覆盖非 Miniblink 适配器转发、失败及未启动状态；发现测试覆盖分页、冻结、可选服务、非法参数、伪造权限和会话撤销。Web 测试覆盖结果校验、分页和旧宿主错误。执行 SDK 构建、公共消费者与实际模板启动。未通过的门槛记录原始结果，不能更新 releaseReady。回退使用变更前源码与对应版本 SDK，不覆盖已发布包。
