# 0.3.0-preview.10 预发布说明

日期：2026-10-08。渠道：preview。版本标签：`v0.3.0-preview.10`。完整工程交付验收已通过，`sourceDeliveryVerified=true`；`releaseReady=false`，生产门槛仍按已知问题跟踪。

## 本版范围

- 公共C++动作契约：可选 `soui.action/1` 标题、说明和有界输入/输出schema；发现结果沿用当前会话授权，原生调用仍校验输入和成功结果。既有未声明契约的方法继续工作。
- 文档能力白名单：由原生应用在bootstrap前配置，页面提交的身份或手势字段不能扩大权限。
- TypeScript动作工具定义与受控界面语义：应用明确注册稳定ID、角色、名称、状态、动作和等待条件，供界面与Agent复用业务流程。完整JSON Schema、UIA和外部Agent认证仍不在本版支持范围内。
- 公共Host转发与受权分页发现；WebView2消费者保持独立实验，不成为默认SDK后端。既有Miniblink模板和Workbench继续默认软件呈现。
- 桌面验收监督器采用单调计时，保留失败结果、超时和原始退出码。WebView2实验修复隐藏启动导致页面计时器停顿的问题；这不说明历史Miniblink长循环超时已定位。
- 新增独立发布验证入口，实际生成、编译和启动应用，验收旧SDK→本版→旧SDK→本版的升级/回退与业务文件保持，以及复制源码到新目录后的重新构建。
- Workbench移除Tailwind构建插件，现有界面所需的utility CSS以静态资源保留；对应MIT许可声明随第三方材料交付。本版依赖审计应绑定最终锁文件记录，不能删除原始失败审计。
- 更新 source-map-js 补丁与 Vue 3.5.43，并复核原有 Vue/Miniblink CSS 缓存兼容补丁；SDK、模板、Demo 最终依赖审计均为零告警。过程与边界见 [ADR-0015](../adr/0015-preview10-web-dependency-maintenance.md)。

设计与边界见 [ADR-0012](../adr/0012-renderer-boundary-and-capability-discovery.md)、[ADR-0013](../adr/0013-experimental-webview2-consumer.md)、[ADR-0014](../adr/0014-action-contracts-and-gui-semantics.md)。

## 复验入口

在版本与源码冻结、固定SDK包已生成后，从源码根目录执行：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File tools/Verify-Release.ps1 -ExpectedVersion 0.3.0-preview.10
```

该入口保留新的仓库外工作目录及 `out/release-validation/<runID>/`。它执行fresh模板、升级基线、升级、回退、再升级和源码复制六次x64 Release独立构建及真实就绪/关闭；最后构建并安装x64 SDK和外部CMake消费者。旧SDK包默认取 `dist/sdk/0.3.0-preview.9`，可用 `-PreviousPackage` 显式指定；`-WorkspaceParent`指定新验证目录的父目录。失败保留现场，不复用历史成功标记。

此入口只关闭其明确范围内的工程验证。发布仍需四组主应用构建/测试、两架构适用依赖重编与运行、依赖审计、实验后端当前版本复验，以及完整汇总、源码清单、归档与SHA-256复核。

## 兼容与限制

更新固定SDK包后完整重编应用，安装器继续拒绝同版本不同内容。旧业务方法未声明动作契约时行为保持；新模板的新公共API需要本版本原生与Web SDK，不能只更新页面。升级/回退验证使用明确兼容旧版本的独立业务小样，不代表新模板可以回退到旧SDK编译。

当前支持边界为Windows/MSVC/C++17；Miniblink页面继续按Chrome 49构建，WebView2现代页面仅在独立实验内使用。Electron等价性能、8小时稳定性、资源收敛、完整目标实机矩阵、输入法/DPI/多屏/无障碍、专业领域模块、跨平台、签名与完整二进制再分发审核仍未关闭。详见 [已知问题](../known-issues.md) 和 [建设路线](../roadmap/agent-gui-framework.md)。
