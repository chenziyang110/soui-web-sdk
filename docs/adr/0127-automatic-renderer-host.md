# 0127 — 可选自动后端宿主

状态：已实现。`preview.2` 冻结快照取得 x86/x64 限定启动、降级及交付证据；
拆分后的 `preview.3` 使用独立身份并单列复验，仍为本地预览候选。

## 背景

现有 `auto` 仅为纯选择策略；兼容与现代模板分别固定 MiniBlink、WebView2。
需要由 SDK 统一完成启动选择，同时保留已有项目与基础 SDK 的依赖边界。

## 决定

新增可选 `Soui::AutoHost` 组件和 `auto` 模板。沿用公开 `webview_host`、Bridge
和各后端退出契约，基础 `Soui::Sdk` 不增加 WebView2 依赖。既有模板默认值不变。

启动前实际探测系统与 WebView2 Runtime。符合现代路径且 Runtime 可用时优先
WebView2；明确 Runtime 不存在或系统只能采用兼容路径时，使用应用随附 MiniBlink。
应用要求现代能力或显式选择 modern 时不得降级。非法配置、权限错误、资源损坏、
异步初始化失败或超时保留原错误，不以通用 catch 切换后端。首版只在创建前选择。

宿主在窗口所属 UI STA 调用。异步准备、取消、Host 关闭与 Runtime 退出分别记录；
关闭完成前保留实例、窗口、Bridge 和消息泵。成功挂载后固定后端，不自动重放业务。
MiniBlink 最终 Runtime 关闭由应用级明确入口处理，不因销毁一个窗口关闭其他窗口。

auto 应用部署独立现代/兼容资源根和同一业务契约。兼容前端按 Chrome 49 目标构建；
现代特性不得未经声明进入兼容资源。离线包包含 MiniBlink 和兼容资源，WebView2
使用已安装或明确指定的 Fixed Runtime，不自动下载。报告区分内置文件和外部依赖。

选中现代后端后，在创建 Adapter 前只读验证用户数据路径及最近已存在父级的目录属性。
仅“文件或路径不存在”可以继续向父级检查；现有文件、非法名称及明确查询错误直接拒绝。
不创建目录、不枚举父目录、不预判写权限。该预检针对已确认不可能成功的配置，
不能替代 Runtime 的异步错误处理或证明所有异常初始化均能及时返回。

## 备选与兼容性

不改变所有旧项目的默认后端，不将两种引擎同时启动，不在页面开始业务后热切换。
不把 WebView2 浏览器存在或计时器节拍视为 Runtime 可用或实际高刷证明。
生成器新增显式 `-Profile auto`；已有 compatibility/modern 的资源、参数与行为保留。

## 验证

执行选择/失败边界回归、打包资源与依赖清单回归、x86/x64 源码构建、仓库外
生成项目构建与真实页面就绪/业务往返/自然退出。分别验证系统 Runtime 优先路径
和真实探测到 Runtime 不可用的降级路径。受控 Runtime 搜索路径缺失的结果必须
与整机卸载 Runtime、Win7/PE 实机结果区分。保留失败，不扩大性能或生产准入结论。
