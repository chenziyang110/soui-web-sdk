04 / Multiple windows

Open the same application in another window with an independent Bridge session. Closing one keeps the others alive.

05 / Native actions

Menu commands belong to this window. Tray availability depends on your desktop host; failures appear in the log.

06 / Application group

Each window uses these same assets and native callbacks. Quit closes every window in the application group.
