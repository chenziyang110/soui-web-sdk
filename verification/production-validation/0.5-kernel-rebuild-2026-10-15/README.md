# 0.5 内核双架构重建原件

两个架构使用公开 Miniblink 源码重建入口、显式 LLVM22MSVC142 档位和
同一物理源码身份，原构建期限四小时、进程排空期限两秒。组件均完成
真实编译链接并自然退出，未继承历史 DLL 的运行结论。

源码快照、工具、参数、链接映射、实际进程捕获与导出差异。大日志使用
无损 gzip，索引同时保留原始及压缩文件身份；静态库保存身份而未重复归档。

旧运行时的 355 个 `wke*`/`js*` 导出与 SDK 所需接口均在。完整导出集合
存在已分类的 STL/V8 及架构相关静态 c-ares 差异，不能声称任意 C++ ABI
相同。上游头中的 25 个原有未实现接口仍不可用。首轮过宽断言失败与
实际接口边界分别保留，见 [ADR 0097](../../../docs/adr/0097-kernel-rebuild-import.md)。

其 EXE 属于较早构建。TLS 生成的私有测试密钥不在归档中。
