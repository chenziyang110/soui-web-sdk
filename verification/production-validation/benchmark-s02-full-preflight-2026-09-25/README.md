# S02 同页面滚动场景配对链路预检

2026-09-25 在同一 Windows 11 x64 主机上，SOUI 已安装 `preview.6` SDK 宿主与固定的 Electron `44.4.4` 宿主使用同一份 React 构建页面，执行 10,000 行滚动场景。每轮将完整页面复制到独立目录并逐文件冻结；独立输入驱动持续约 61.8 秒，采样器记录整进程树；两端宿主、输入和采样器均退出 0。原始页面、输入、进程树、宿主日志和页面副本保存在 [raw/](raw/)。

三对样本的[第 1 对](pair-preflight.json)、[第 2 对](pair-preflight-run2.json)、[第 3 对](pair-preflight-run3.json)均通过组合**预检**：页面场景、10,000 行 fixture、1100×720 内容区、动作序列、页面文件、运行机器、工具和宿主身份匹配。组合预检只认定数据可追溯和可配对，始终输出 `benchmarkValid=false`、`releaseReady=false`。

| 配对 | 顺序 | 运行时段（北京时间） | 使用方式 |
|---|---|---|---|
| 第 1 对 | SOUI → Electron | 09:29–09:31 | 并行 QEMU（PID 71492）运行，保留为链路诊断，排除正式性能统计 |
| 第 2 对 | SOUI → Electron | 09:33–09:36 | 未观察到 QEMU，作为隔离条件下的探索样本 |
| 第 3 对 | Electron → SOUI | 09:36–09:38 | 未观察到 QEMU，作为反向顺序探索样本 |

隔离条件下两对样本的整进程树 Private Bytes p50：SOUI 约 52.2 MiB，Electron 约 233.5–233.6 MiB；整机容量 CPU p50：SOUI 约 3.04–3.08%，Electron 约 0.05–0.14%。这些数值只说明采样器在该主机、该场景观察到了不同资源分布，**不能据此判断流畅度、能耗或整体采用价值**。输入到实际屏幕呈现没有测量；样本不足五对，也没有完成冷/热启动、其他场景和目标系统重复验证。

准备继续第 4–6 对时，新的 QEMU 实例（PID 25444）在 09:39 启动，隔离检查在第 4 对开始前停止，没有新增受干扰样本。下次须在无并行负载窗口补足至少五对交替轮次，并采集物理呈现及冷/热启动。Win7 SP1 x86 的实际 QEMU 短测保留在各自验收目录；本 x64 对照不能替代 Win7 或物理设备验收。
