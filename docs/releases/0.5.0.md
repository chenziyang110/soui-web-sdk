# SOUI Web SDK 0.5.0

2026-10-16，预发布交付，未签名。下载见 [GitHub Release](https://github.com/chenziyang110/soui-web-sdk/releases/tag/v0.5.0)。

0.5.0 完善独立 C++/TypeScript SDK、Modern 桌面模板、Agent 动作与可选 Windows UIA 能力。

- 帧节拍支持 30–1000 Hz 整数，修复 100 Hz 被降为 60 Hz；显示配置变化时更新节拍。
- Modern 模板使用 WebView2，提供独立应用 ZIP；兼容模板和 Workbench 分别交付。
- 改善异步启动、取消与关闭顺序，等待实际 Runtime 和浏览器退出。
- 任务、动作和 GUI 语义提供权限隔离、取消、状态查询及通知；普通请求、清理和续期采用独立有界容量。
- 修复独立 SDK 构建、安装消费者、LLVM 发布入口和深层许可路径；两架构固定原生依赖已从记录的源码重新构建。
- Windows 资源发布遇到短暂 EPERM/EACCES 时采用最多五次、总等待 450 毫秒的重试；持续失败仍报错并恢复旧资源。

## 本次验证

- x86/x64 × Debug/Release 四组实际构建通过。
- 两架构分别执行一次 Release 关键回归，每架构 208 项原生用例全部通过，未跳过原生用例。Web、SDK 安装与发布工具相关回归也通过。
- 两架构独立安装 SDK，并以公开 CMake 消费者引用当前 Soui::Sdk，完成编译、链接和执行；Modern 采样另以外部宿主引用当前 Soui::WebView2。
- 六个应用 ZIP 解压后的八个启动场景通过。SDK 包完成逐文件、源码和两种运行档位核验。
- 本机 Windows 11、100 Hz 主屏上，WebView2 S05 自动触发动效并连续采样 120 秒；页面 requestAnimationFrame 调度间隔中位数 10.000 毫秒，对应约 100.00 Hz。该样本证明本机超过 60 Hz 的运行节拍，不代表合成画面无丢帧、持续 100 fps、光学校准或完整性能对比。

## 交付与升级

交付包含完整源码包、独立 SDK 源码包，以及两架构的 SouiStarter、SouiModernStarter 和 SouiWorkbench，共八个 ZIP。每个 ZIP 附 SHA-256；发布附件中的 Release-Manifest-0.5.0.json 和 SHA256SUMS-0.5.0.txt 汇总最终身份。Modern 小应用包要求系统已有 WebView2 Runtime。

公共 C++ 布局和最终关闭接口有变化，请使用整套 SDK、对应内核并重新编译应用；不能只替换单个 DLL。不要将内部候选包与本次固定 SDK 包混用。具体关闭与回退方式见[版本与升级](../versioning.md)。

## 保留的限制

按维护者要求，8 小时长会话、千轮生命周期、完整性能对照、重复搬移重编及完整升级/回退矩阵留待后续。本版未完成完整 OS/PE、IME/DPI/多屏认证和授权审核，生产验收保持 `releaseReady=false`。

严格桌面截图采样因累计帧数大于一而拒绝通过，失败原件已保留；本轮没有通过合成画面、实际输入响应或实际显示帧率认证。此前 Source29 的 UIA typed-owner-focus 偶发失败未确定根因；本版增加错误码、实际焦点和阶段时间诊断，后续通过不抹去原失败。历史资源目录拒绝的具体占用方也未确定。完整限制见[已知问题](../known-issues.md)。
