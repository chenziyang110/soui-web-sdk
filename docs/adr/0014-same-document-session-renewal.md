# ADR-0014：同文档授权续期与稳定资源归属

- 状态：proposed；公共 API、权限及关闭顺序变更，合并前需维护者评审
- 日期：2026-09-26
- 开发版本：`0.3.0-preview.11`
- 范围：[生产验证方案](../roadmap/0.3-sdk-validation.md) V01-06；真实长稳仍单独验收

## 背景

现有授权在 30 分钟后拒绝新请求。Web 客户端缓存凭据，公共任务、扫描根、媒体文件与旧业务订阅精确绑定 token。重新 bootstrap 或重载会更换会话，不能证明原任务和订阅在八小时运行中保留。授权校验与业务提交之间还可能发生关闭，必须同时处理撤销后的迟到入队。

## 决定

原生应用在 bootstrap 前显式启用 `bridge.session.renew`；`json_bridge.enable_session_renewal()` 默认不启用，Starter 与 Workbench 显式启用。bootstrap 增加可选 `lease` 对象：`generation`（从 1 开始）、`expiresInMs`、`renewAfterMs`。未启用的应用仍保持有限 30 分钟授权。不得由 Web 请求修改期限、权限、来源或会话。

`bridge.session.renew` 只接受 `{operationId}`，ASCII 字母、数字及 `-_.:`，1–128 字节。成功返回 `{sessionId, origin, token, lease}`，会话、来源及能力集保持不变。只有未到期的当前令牌在剩余期限不超过 5 分钟时能够轮换，轮换后有效期为 30 分钟；过早请求返回 `E_RENEW_TOO_EARLY`。新令牌使用 Windows 系统加密随机数 256 位，熵源失败不修改原状态，不降级为计数器或时间值。新增系统链接库 `bcrypt`，不提高 Windows 7 SP1 下限；依据 [BCryptGenRandom](https://learn.microsoft.com/en-us/windows/win32/api/bcrypt/nf-bcrypt-bcryptgenrandom)。

每个授权只保存当前令牌、上一令牌和一份操作记录。上一令牌仅在 `now < min(轮换时刻+30秒, 上一令牌原到期时刻, 当前到期时刻)` 内有效，期间仍可授权原能力集内的普通业务请求。对于续期方法，上一令牌只能用相同 operationId 重取同一个新令牌及固定到期时间，不能再轮换；operationId 仅是幂等键，不是秘密。当前令牌的相同操作重试也不再次轮换。重取响应计算剩余时间，不重新延长原到期时间或重叠窗口。续期失败、过期、撤销均不能回退到匿名 bootstrap。

原生 `authorization_scope` 是不可伪造构造、不可复用的共享授权对象，保存稳定身份及实时撤销/期限状态。资源归属比较此对象加 session/origin，不再保存 bearer token 作为资源身份；同会话另发授权仍不能访问原资源。transport 从本次凭据校验结果填写原生 `bridge_request.authorization`，始终覆盖调用者传入值，JSON 不接受此字段。直接 scanner 入口也自行解析真实凭据，不能信任调用者附带身份。公共任务的直接 C++ 调用必须传递经过 permission_store 解析的授权对象，禁止空对象降级为会话比较。

关闭先撤销授权，释放权限锁，再按资源锁清理任务、扫描、媒体、文件和订阅。新资源在自己的提交锁内最后检查授权仍有效；关闭之前提交的资源由后续清理覆盖，之后的提交必须拒绝。不得持权限/全局桥锁调用业务处理器、事件 sink、原生模态对话框或 join 工作线程。已经复制并开始分派的事件不能通过退订追溯撤回；Host 的文档代际过滤继续负责旧页面隔离。已接纳任务仍采用协作取消，授权到期不自动证明任务已停止；到期后不再新投递授权订阅事件，关闭负责最终清理。

Web 同一个客户端提供 `renewSession()`，仅一个续期在途。带 lease 的连接自动提前续期，使用有界控制请求容量，失败重取沿用原 operationId。回应必须核对 session/origin、字段界限及递增代际；从发送时刻保守估算本地期限，迟到回应不延长估计、不覆盖较新凭据、不复活 disposed 客户端。续期保留 pending 请求、taskId、subscriptionId 和 sequence。普通业务调用仍在调用栈内同步发给原生，不等待续期且不自动重放，以保留真实输入手势。dispose 停止计时器和续期，退订结果仍以原生确认为准。

Host 为续期提供受限控制容量；这不能抢占已运行的模态处理器。休眠、长模态或计时器停滞跨过原生到期时间将明确失败，需应用告知用户重新加载；不承诺永不断连。真实八小时验收必须覆盖正常续期并记录这些边界。

`client.sessionLease` 返回当前本地保守剩余期限的副本；手动 `renewSession()` 早于本地续期时间时返回当前 lease，不发请求。自定义连接可以传 `leaseElapsedMs`，只能扣除 bootstrap 往返已消耗的时间，不能增加寿命；标准连接器和 Workbench 均记录发送起点。Web 一次续期最多三次尝试、总预算不超过 25 秒且不超过旧凭据本地剩余寿命，不能让重试刷新这份预算。原生响应等待表保留 384 个普通/清理等待加 1 个续期等待，Host 保留 256 个普通、128 个清理和 1 个续期槽。该容量隔离不是抢占正在执行的处理器。

## 备选、兼容与迁移

重试采用有界退避：第一次失败后等待 250 ms；最后一次发送留到固定总截止前至多五秒的响应窗口，并至少退避 500 ms。三次用尽后不发送第四次，但保留原截止内尚未完成的确认。实际 Host resolver 超时会删除原等待，不能恢复它已丢弃的确认；恢复通过同 operationId 的后续请求重取。自定义端口仍未决 Promise 的迟到成功是另一条路径，不得混为真实 Host 已恢复。最终失败后该客户端不新建续期操作或重启 bootstrap，应用收到明确错误。

为使旧 Demo 业务在长会话中保持有界，旧订阅集合与公共任务一致限制为 128 项；退订确认或会话关闭释放容量。原生任务与扫描的外部事件 sink 异常被隔离，不能使工作线程逃逸。Demo 所有已发行会话在析构时撤销，worker 服务成员的析构/join 早于其捕获的回调状态，已复制回调仍有有效状态可访问。真实媒体处理与模态对话框需另外验收，归属夹具不能代替这些路径。

拒绝无限期 token、每次业务请求自动延长、静默重载或只按 session 放宽资源归属。稳定身份与轮换令牌分离能保持资源所有权，并仍限制旧 bearer 使用时间。preview.11 增加公共 API 与 bootstrap 可选字段；直接调用 task_service 的原生消费者需从 permission_store.resolve 获取授权对象。旧 Web 客户端不解析 lease 时仍按原 30 分钟期限失败。目录根令牌、扫描 cursor、媒体文件令牌和已存在订阅不重新创建。

## 验证

原头文件暴露的 `permission_grant` 值结构由不可复制构造的 `authorization_scope` 替代；曾直接依赖该值结构的原生代码需要迁移。所有原生消费者须与 preview.11 SDK 一起重新编译，不保留旧静态库的布局兼容承诺。

用原生私有可控时钟验证 25/30 分钟边界、多轮模拟八小时、上一令牌截止、丢失确认、固定大小状态、熵源失败、独立授权隔离和撤销准入竞态。Web 验证 single-flight、容量耗尽、乱序/迟到回应、dispose、事件顺序、手势同步发送及真实连接器。公共任务与 Demo 各类长期资源都需证明跨轮换保留。x86/x64 构建、安装后独立接入及生成模板分别验证。

模拟时钟、单元测试和编译不能代替超过 30 分钟、八小时、真实窗口与 Win7 SP1 x86 客体验收；当前所有生产门槛保持未通过。其他 QEMU 或桌面长测运行时不启动并行桌面负载。
