# R41 WebView2 持续负载与原生 owner 输入夹具

本目录是17个冻结源文件的原字节快照，不含二进制、开发机操作驱动或自动启动入口。原目录的v14314.44/Windows SDK19041 x64消费者和输入器实际构建自然退出0，14项纯规则合同通过。此副本所在目录没有重新构建；制作快照时尚未运行真实窗口，不能将编译或模拟合同称为性能验收。

独立的 `r41-default-native-strip-v1` 使用1100×792 owner窗口和1100×72原生child strip，在同一个STA处理真实WebView2 Bridge回复。工作为30秒4KiB、7条echo在途，加最多1条控制；输入为25秒3125次/125Hz。页面在收到真实首个echo回复后才启动输入，并在原30秒截止前接收一次完成fence，不能仅凭延迟的native phase消息裁定输入处于JS负载内。它测的是原生strip接收机会，不是WebView2 DOM输入、帧率或物理反馈。

`project/`含Host、输入器、冷/最终marker和有界完整账本；`tests/`与`project/tests/`是定向读取、页面和纯策略反例。`analyze.cjs`要求全部3125项、实际发送参数、单调标签和原生来源、前后台/几何及完整scalar终态；不裁样，不把tag0当预定输入。实际运行还需冻结SDK4/WebView2库、固定浏览器Runtime、相匹配的产物身份及独立控制入口，均未复制到此处。输入明确授权后才能启动；Esc、失焦或尺寸变化应终止后续输入并保留失败。

两阶段Job快照仅记录调用进程所在直接Job的原始计数和查询区间，失败为null。它不认证完整应用/共享浏览器/GPU归属、负载区间峰值或物理显示。计数含义和非原子边界不能因查询成功而升级。SDK、默认参数、原私有桌面prototype及旧失败均保持；此新profile不能替换旧prototype的身份。

源清单按相对路径记录原证据来源、字节数和散列；不包含自身散列。复制和新增说明不运行原生测试，也不更新性能或生产资格。
