# ADR-0131：统一桌面前端类型与薄适配层

## 背景

统一桌面已注入 `window.souiDesktop`，业务仍需手写调用和缺失宿主检查；旧 `sdk/web` 使用不同协议，不应混用。

## 决定

新增独立 `sdk/desktop/frontend/desktop.mjs` 和相邻 `.d.mts`。仅委托当前注入的 version 1 API，不发送原生消息、不持有 token、不模拟权限、会话、重试或取消。宿主检查立即返回，不轮询或宣称引擎就绪。泛型只提供编译期业务提示，不代替运行时业务校验。资产解码限制为既有 256 KiB、小型 base64 结果，严格校验大小与编码，UTF-8 文本失败显式报错。

SDK 安装原文件；生成器把同一来源复制到项目 web 目录，普通 JS 可直接运行，类型检查可选，不增加下载或构建依赖。已有项目和 preload 不变。

## 备选与兼容

不复用旧 Web SDK 协议，不添加第二套 RPC。无宿主不自动回落浏览器假实现。原生错误保持原样；本地适配错误有独立代码。原生 30 秒超时、pagehide 拒绝、无硬文件 I/O 取消的行为不变。

## 验证

本轮仅执行语法、薄适配运行时边界和生成器集成必要检查；若已有 TypeScript 编译器则检查声明。三引擎 GUI、完整回归及目标机类型工具链留待统一验收。
