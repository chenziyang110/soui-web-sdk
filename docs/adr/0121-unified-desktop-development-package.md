# ADR-0121：统一桌面开发包入口

状态：开发包实现；不是发布流程或平台运行验收。

## 决定

提供 Node.js 无依赖入口，接受已配置的桌面构建目录，以参数数组调用 CMake
构建、CTest 和安装，再将安装树制作为 ZIP。三端使用同一条命令，不自动下载
依赖，不猜测宿主架构为目标架构。目标身份读取安装后的 CMake 包元数据。构建前后均核对实际缓存，拒绝不存在的多配置目标；安装版本必须与源码 VERSION 一致，且选中配置的 Runtime / Desktop 静态库必须齐全。

输出目录必须不存在；失败保留现场且非零退出，不删除或覆盖任何已有交付。
拒绝安装树中的符号链接和特殊文件，逐文件 SHA-256 清单与压缩包 SHA-256
分别保存。文件内容摘要加入开发包名，避免把不同开发快照当作相同正式版本。

这个入口只生成 SDK 开发快照，不创建应用安装器、签名、公证、自动更新或
新 GitHub Release，不修改 VERSION 或已发布包。打包前通过 CTest JSON 注册清单核对七项必需测试必须唯一、启用且有执行命令；缺项不能用其他测试通过代替。通过的 CTest 仅表示注册的
测试通过，GUI、目标架构运行和授权审核仍需独立验收。

## 备选与兼容性

没有复用只适用于旧 Windows 交付的 Package.ps1，也不把不同系统依赖强行
捆进一个所谓通用二进制。现有 CMake 安装入口保持不变；依赖仍由目标机提供。

## 验证

单元测试覆盖参数、缓存身份、失败中断、拒绝覆盖/符号链接、目标身份与摘要。
在可用平台实际运行完整命令并测试安装消费者；未执行平台明确列为未验证。
