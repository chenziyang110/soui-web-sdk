# ADR 0126：可选压缩档位与实测开销

- 状态：已实现候选，限定验证通过
- 日期：2026-10-23

## 决定与兼容

应用打包保留默认 ZIP、原文件名及原参数 -tzip -mx=5 -mmt=2。新增显式
7z-balanced 和 7z-small 档位，使用 LZMA2 固实块、显式请求 32 MiB / 64 MiB
字典和两线程压缩配置。普通应用和第二批 Bundle 使用同一档位定义；非默认
输出带档位后缀及 .7z 扩展，避免与 ZIP 或另一档位混淆。

档位只改变传输封装，不改变载荷、应用后端、运行目录或 SDK 包身份。
报告保留原 compression 字符串，新增明确 profile、format、字典、solid、
完整实际参数与归档工具及编解码库身份。不按文件名推断格式，也不覆盖已有归档。
默认 ZIP 与现有调用方保持兼容，新的 7z 档位要求消费者有匹配的解压能力。

## 测量契约

固定同一份实际应用和 Bundle 输入，按架构和布局分别比较三个档位。
记录压缩字节、实际压缩耗时、三次独立解压耗时和被测进程的内存峰值。
内存度量来自 Windows 进程/Job 记账，区分私有提交量和工作集，不把字典
参数当作总内存。测量只覆盖压缩/解压进程，验证哈希时间另计，不冒充应用
运行内存、安装器整体内存或冷缓存性能。

每个归档完整性检测通过后实际解压，每次逐文件比较原字节/散列；Bundle
继续验证和恢复。保留工具版本、散列、输入身份、原始轮次和异常。串行测量，
各次使用全新任务目录；失败和不完整计数不作通过，不能删异常点换取结论。

## 备选与边界

不全局切换 NSIS solid，不改变在线/离线安装方式，不替换内核。更大字典
不保证更小归档，默认档位不依据单个样本自动改变。只测 ZIP 字节不能替代
解压时间和内存比较，短轮次测量不代表所有机器或目标系统矩阵。

## 验证与交付

覆盖旧 ZIP 默认、显式 ZIP、两种新档位、Bundle、错误参数、预算拒绝、
元数据、格式和工具身份、归档冲突及实际解压一致性。使用新的独立目录
测量，不覆盖前两批证据或固定已发布 SDK 包。完成后记录真实数据和范围。

`preview.1` 的真实应用[历史测量摘录](../../verification/production-validation/auto-host-pr-2026-10-23/historical-compression.md)
保留冻结输入身份、归档大小、耗时和工具私有提交量峰值。拆分后 `preview.3`
复验单列，不把历史收益当作新版本已测结果。默认仍为 ZIP；数据不代表业务
安装器或目标系统认证。
