target compiles only its test translation unit, and MAP must extract the current

The primitive controls use tiny explicit values as arithmetic fixtures only.
The public fixture derives its finite cap from that exact future runtime/STL
sample, not a production calibration. Constructor zero may fail on real MSVC
empty-map allocation; no object/receipt is read after that failure. Bridge
contexts precede Bridge lifetime and its natural Service destructor join.

The additional native typed case must use the public windows_local_endpoint
factory, an actual held native peer and the registered local task family. It
must start/query by operation through that same Bridge, force cap-minus-one
without publishing operation/accepted/taskId, then explicitly reuse the operation
with smaller lawful input and prove duplicate does not rerun. Owner pump,
endpoint request_stop/poll_stop and actual natural I/O/worker joins must complete
before borrowed contexts or Bridge are destroyed. Existing public endpoint
Source anchors are pinned, not borrowed as a new pass. GUI prepare/refusal must
also release its actual borrowed context and keep existing authorization rules.
These typed/GUI and full terminal fault runs are not implemented/executed by
this minimum public page regression target and remain required coverage before
production-default/long-run qualification, not hidden passing tests.

Owner epoch exhaustion and denial saturation must be forced in a separately
reviewed bounded counter harness or established by an independent source proof;
never iterate UINT64_MAX times. Zero epoch/invalid/exact=false must fail the new
sample gate while actual quota remains enforced independently of diagnostics.
Record source, clock, PID+FILETIME and owner lifetime through the actual caller.
This Source does not add a production serializer/collector or alter old schema1.

Fresh Root actual build/test/result and a genuine independent source peer are
mandatory. Production policy, calibrationPin, fullCacheBudget and releaseReady
remain null/NOT_EVALUATED/false, including after finite fixture success.
