# ADR-0018：Workbench 依赖更新与构建环境

日期：2026-10-08。状态：accepted；用户明确要求处理并合并 PR #58。

## 背景与决定

Element Plus 2.14.7 引入 VueUse 15，后者正式停止 Node.js 20 支持。Workbench 声明的 Node.js 20.19 下限与上游要求不再相符；整体 0.4 工程因现代模板已要求 Node.js 22.12 以上。

更新 React Query、Element Plus 与 Sass，并将 Workbench 的构建环境声明为 Node.js 22.12 以上。基础 SDK 和兼容生成项目的 Node.js 20.19 支持范围保持原样。应用运行时不需要安装 Node.js，Windows 和 Chrome 49 构建目标不变。

更新依赖清单和法律材料会改变固定 SDK 内容，因此使用 0.4.0-preview.3；不覆盖已经冻结的 .1/.2 包或发布标签。此前验证结果继续绑定此前源码，不自动继承。

## 备选与迁移

将 VueUse 强制覆盖回旧大版本会偏离 Element Plus 的依赖契约，没有上游支持依据；仅忽略引擎告警也无法证明兼容。现有 Workbench 开发者须将构建环境升到 Node.js 22.12 以上，再执行干净安装、构建和验证；只使用基础 SDK 或兼容模板的项目仍可使用原构建环境。

## 验证边界

在声明的最低 Node.js 22.12 环境严格检查依赖引擎，执行前端类型检查、构建、审计、兼容产物检查及两架构实际原生启动。SDK 新身份须打包并核对源码匹配，验证标准生成项目接入。实际结果另行记录；本次合并不发布新版本，不关闭完整 Windows/PE、长期资源或生产准入门槛。
