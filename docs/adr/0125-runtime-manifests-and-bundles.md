# ADR 0125：显式运行时依赖与包内内容去重

- 状态：已实现候选，限定验证通过
- 日期：2026-10-23

## 背景与决定

原应用部署通配复制 SOUI DLL 和递归复制 CRT；多个应用归档分别携带相同运行时。
SDK 增加显式运行时清单、可选组件选择及独立的内容去重应用包。旧项目的默认
运行文件集合和独立应用 ZIP 保持兼容，不替换已有固定 SDK 包。

运行时清单按 x86/x64、后端和组件记录相对源路径、部署路径、字节数与散列。
默认兼容集合覆盖当前正常 SOUI、MiniBlink 和 CRT 文件；现代集合只带其所需
CRT。组件依赖闭包显式声明，动态加载组件不能通过静态导入扫描擅自删除。
部署在写入前验证完整选择，生成自有文件身份记录；仅退休原记录拥有且未被
修改的文件，保留其他业务文件。失败恢复旧部署，不把半完成操作当作通过。
已批准 DevTools 配对内核继续沿用其来源和外部散列校验，不静默回退普通内核。

去重包采用新版本格式，保存逻辑文件清单和按内容身份命名的数据块。同一内容
只存一份；同名不同内容保留两份。展开先校验完整包，再复制出原有各应用目录，
不创建共享硬链接，不改变运行时 DLL 查找或进程隔离。清单区分应用、架构、
后端与原载荷身份。默认打包仍为已有单应用 ZIP，新格式由调用方显式选择。

## 备选与边界

- 全局共享 DLL：引入其他产品升级、丢失和卸载依赖，不作为本次方案。
- 按同名合并内核：不能证明二进制或职责相同，不采用。
- 仅启用固实压缩：不能建立运行时依赖或恢复契约，收益另行测量。
- 本轮提供 SDK 工具和格式，不推定下游 NSIS 安装/卸载运行时已去重。

## 兼容、迁移与验证

不改变 C++ ABI、最低系统、Web 后端或现有默认压缩格式。运行时文件未被替换，
新清单属于部署契约。使用新内容须发布新的 SDK 身份，不覆盖已发布 0.5.0。
回退使用原 ZIP 和完整独立应用目录。

验证覆盖默认集合一致、组件依赖、两架构文件身份、同名异内容、受损或缺失块、
不安全路径、业务文件保留、失败恢复、完整解包逐文件一致、现有项目及第一批
功能回归，并执行仓库外 CMake/原生消费验证。真实结果在完成后单独记录；
不把本轮工具验证扩大为生产或目标系统矩阵验收。

共享工作区历史验证包含 x86/x64 实际编译和恢复后内核加载。默认运行文件各
59 个，与原集合一致；两份相同探针应用的去重收益不能推算成下游安装器收益。
