# 0.6.0 DevTools 长测交接

本轮普通 Release 将低收益长测后置，具体范围见 [0.6.0 发布说明](../releases/0.6.0.md)及 [ADR-0136](../adr/0136-0.6.0-release-scope.md)。本文件不启动实验、不改变验收门；`releaseReady=false`、`productionQualificationComplete=false`。D07、D13、D14 及下列环境资格仍未完成。

历史必要短测只属于各自原输入。最后的 preview.9 MiniBlink x86 来源发布代表 case11：PID 4396、creation FILETIME `134376585797743394`，原预算 120000ms；目标退休 111234ms、finish 111391ms，7 个认证脚本 receipt、回调 0、`resourcesRetained=false`、原句柄自然 exit0/Dispose。其 EXE SHA256 为 `b2c804b30b7e04c14376beb5bbc184b0a21fdb1cafd9098f2a93dcf030e17254`。这不是当前 0.6.0 重建载荷的运行证明，也不关闭 whole D01/D05/D08。外置 map 的原结论只包括运行未见额外来源发布及绑定前端的静态 no-fetch，不包括网络 trace 或私有拒绝码。旧失败、超时、强清和输入排障记录保留，不转挂到新版本。

## 必须保留的测量条件

| 项目 | 必须实际完成 | 当前边界 |
|---|---|---|
| D07 业务租期 | 真实暂停/恢复、后台任务、订阅、续租及未续租到期。业务 TTL 为 30 分钟，只有最后 5 分钟可续租；首次合法续租不得早于实际启动约 25 分钟，未续租分支须真实越过原 30 分钟期限。 | DevTools grant 到期和业务租期到期分别观察；已有续租模块不能替代未续租到期分支。 |
| D13 生命周期资源 | 每个声明支持的 backend/architecture 各完成 1000 次真实打开/结束；同一原进程持续运行，预热、校准、收尾不计入 1000 次。 | 不用进程重启、强清或合成 reducer 数据补足次数。 |
| D14 持续负载 | 每后端在主认证环境实际完成预热后 28800000ms（8 小时）混合调试和业务负载；每个冻结覆盖窗口都取得真实动作 receipt。 | 提交队列、定时等待、总计数及短例不替代窗口内真实动作。 |

业务租约实现见 [permission_store.cpp](../../sdk/src/runtime/services/permissions/permission_store.cpp)，授权与结束合同见 [DevTools](../devtools.md)。禁止缩短 TTL、加速或更改时钟、自动续调试权、放宽资源/授权 fence，或重放已有业务副作用。续租成功与暂停导致未续租到期分别保留 session/代际、sent/received tick、renewalDue/expiry tick、业务结果和预期拒绝分类。

Debug/Release、全部 OS/PE/Win7 与其他未认证平台、中文 IME、DPI/跨屏、多窗口、非管理员、升级回退、WebView2 最低/当前 Runtime 及 Fixed/Evergreen、D12 冷热统计、完整性能比较和其余故障矩阵仍保持各自未验证或部分验证。x64 不认证 x86，Fixed 不认证 Evergreen，单后端不认证另一后端。

## 已有入口与证据的适用范围

公共源码提供 [DevTools 合同](../devtools.md)、[原生测试目标](../../tests/native/CMakeLists.txt)及 [Test.ps1](../../tools/Test.ps1)。短测试与构建工具不会自动产生 D07/D13/D14 认证。长测接手者须取得与所选源码、SDK prefix、内核、前端和 Runtime 配套的消费者、plan、采样器及分析器；标准 SDK 不提供已冻结的通用长测一键命令。

历史 Source3 的真实构建记录 SHA256 `cce8c1f608ba3fb8f65b844ec01ad50c54e6b0624329d44fd9942dc4a0fe5d40`，六载荷文件部署记录 `e0715e0b23f3fdd25d5bdf8cedef909556297164975109dac87316774a58fbab`，独立实际核对 `eef7eb383fd9d038d96eafa9708a354bfa858b4f509ebb2d9767aadcbdeef39d`。它们只证明原构建及文件部署，没有证明长测运行或当前 0.6.0 输入。历史 WebView2 count profile 限其原 x64 Release preview.6 身份和预算，不直接套用后来的 preview.9/x86 或本版。

既有长测原生接口形状为 `ABS_REVIEWED_EXE --plan ABS_PLAN --output ABS_FRESH_OUTPUT`；D13 的 `--describe` 只描述身份。它们不是本版可立即执行的命令。CLI、文件、SHA 和网页不能代替两阶段默认 No 的真实原生准入。MiniBlink、WebView2 的 D13 分析器与 D14 reducer 各有合同，不互换；`dataReadyForIndependentReview` 也不是验收通过。

## 接手与执行顺序

1. 指定执行 owner、唯一 GUI 操作者及非作者基线/结果审查者。启动前冻结 backend、architecture、configuration、OS/机器、Runtime 类型/版本、工作负载、预热/校准、采样间隔、覆盖窗口和完整 plan；不先运行再选阈值。
2. 复用获授权的后台 VM，并持有独占输入 lease。GUI 只通过受支持的来宾画面操作，不在宿主运行产品 GUI，不用进程注入、QMP 键鼠或自写远程输入替代真实原生确认。不要为排障另造 VM、删失败或重启原测量进程。
3. 绑定源码集合、SDK 三库/生成头、EXE、内核、批准前端及全文件闭集、fixture/JS/map、runner、sampler、reducer、plan 和 Runtime 整树身份；另核 Guest OS、实际加载模块与 profile。宿主散列不冒充 Guest 加载。输出使用全新目录，不能写入已校验载荷。
4. 同一原进程依次完成 warmup → calibration → await-freeze → measurement → finishing。非作者根据真实噪声、采样开销与资源域基线冻结数值 growth/slope 阈值及 review pin，再走原生默认 No 准入；失败后不放宽阈值追认。
5. 真实执行业务调用、日志洪水、网络错误、暂停/恢复、reload 与业务续租等冻结工作负载。按原合同保持 A/B 业务轮换、B reload、A Inspector 与 B 无 grant；保留每个覆盖窗口的实际 receipt。D07 的到期、订阅、后台任务另有明确预期，不能只凭 renewal 动作存在宣称覆盖。
6. 保留原 consumer PID/creation FILETIME/句柄、UI owner、Host/文档/operation/许可代际和 Job/cohort。whole epoch 从原进程开始，包含 consent、校准、冻结等待和收尾。新长测 plan 在启动前选足真实八小时及开销的 whole budget；不延长旧短例 120s，不重置 open/end/runtime/action 截止。保留既有共享 2000ms drain、数据容量和物理退出要求；分段持久化、短轮询续接不重置时钟，不拼接中断实验。
7. 原生 revoke、Host、Runtime 和 worker 真正退休后核 fresh 原 Job cohort，记录残留。保存 context、ready、原始 NDJSON、stdout/stderr、EOF、returned/terminal、原句柄自然退出及 Dispose；非作者交叉核对分析、原始行为、媒体、阈值和身份。消费者或分析器不能自授生产认证。

## 资源趋势、停止与结果

至少保存 PrivateBytes、WorkingSet、kernel handles、threads、USER/GDI、views、pending/active callbacks、ownedProcesses 的原样本、时间和来源。比较预热后分段中位数、首尾增长、slope/hour，并保留峰值、异常与操作延迟。不能仅看最终内存，或强制 GC、重启、杀进程掩盖增长。

MiniBlink 的目标回调域、全引擎域和原 Job 成员分别说明；未覆盖域不补零。WebView2 Controller 引用和 SDK COM 回调不冒充 Chromium 内部队列、全部进程或 Inspector 窗口。unknown、busy、fault、过期 cohort、丢行、样本断档及覆盖缺口按原值保存。

触发冻结 plan 的失败、权限越界、意外来源暴露、崩溃、预算/容量超限、采样身份变化或 owner/回调无法排空时，停止新工作，继续原时限内清理并保存首次失败。关闭结果不可靠时保持 pending/failed 和 owner；强清只记失败处置，不计正常周期或自然成功。不自动重试、删除失败、刷新期限或豁免残留。

目前仍缺本次长测的完整冻结 plan、目标机身份、真实 calibration/baseline、数值阈值、D07 专属到期预期、当次 1000 周期/8h 原始数据及最终独审。后续只按输入变化、实际失败或未解决风险重跑受影响检查；提交号变化本身不要求重跑已匹配身份的短测，新二进制/环境也不能继承旧通过。
