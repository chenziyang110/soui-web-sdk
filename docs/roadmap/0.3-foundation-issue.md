0.3 首个实现切片：可信源码与运行载荷、干净资源部署和单应用体积基线。

0.2 的完整源码清单含未跟踪文件和工作目录换行散列；资源重复构建会保留旧文件；原生验证仅绑定 EXE/内核，页面修改后仍能复用成功记录。这些问题会使后续性能/体积优化缺乏可靠基线。

本改动恢复被忽略的必需依赖源码，定义可搬移的源码身份与发布暂存，绑定构建/测试/打包的完整运行载荷，替换旧 Web 资源，分别输出最小模板及 Demo 的大小报告。设计见 ADR-0001。

验收：换行/遗漏/额外文件/资源篡改/旧证据的回归测试；新源码目录验证与构建启动；x86/x64 本机验证；干净单应用大小报告。保持私有仓库、无远程 CI、preview 和 releaseReady=false。完整 Electron 性能对照、异步 Bridge、多窗口等后续工作包仍需继续实施。
