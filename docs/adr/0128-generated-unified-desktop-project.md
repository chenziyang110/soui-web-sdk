# ADR-0128：统一桌面最小项目生成器

状态：未发布开发入口，目标平台运行仍待验收。

## 决定

新增独立 `templates/unified-desktop` 和无外部依赖 Node 生成器，不替换历史
Windows 模板。生成已安装 SouiDesktop 的最小 CMake consumer：单窗口、明确
allowlist 的 Bridge、显式启用本地 HTTP 资源服务、前端模块/fetch 和应用 staging。
模板不包含 Workbench/多窗口演示业务，不下载 SDK、不执行生成项目或包安装。

生成器只接受有界可搬移应用名、反向 DNS 标识、应用版本和新目录；拒绝已有
输出、symlink、特殊文件、非法名称/碰撞与模板树重叠。只替换三个明确 token，
模板和生成文件不嵌入开发机绝对路径；SDK 前缀由消费者配置时传入。生成工具和
模板一起安装到 SDK 的 share/SouiDesktop，源码和安装布局均可调用。

生成过程不自动删除失败产物；部分失败明确报错，交付者选择新目录重试。输入
模板须可信且不可并发修改，检查不宣称解决恶意 TOCTOU。生成的应用默认版本
0.1.0 与 SDK VERSION 无关，不复制或改写 SDK 许可、不生成正式发布声明。

## 备选与兼容性

仅提供示例需要手工拆除业务和拼装配置；复制完整演示会扩大接入面。故独立小
模板，复用既有公共 API、CMake staging 与 doctor，不建立第二套打包逻辑。
用户已有项目和默认 SDK 行为均不变，HTTP opt-in 仅属于新模板自身选择。

## 验证

只执行生成边界/语法重点检查及一次仓库外真实生成 consumer 的配置、构建和
staging。Windows/macOS 编译、三引擎交互、实际安装依赖和完整回归延后；生成
成功或 Linux 编译不代表跨平台运行通过。
