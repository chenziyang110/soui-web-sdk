04 / Multiple windows

Protection blocks title-bar, menu, and page close requests. Uncheck it to discard the simulated changes. Reload/navigation resets this example's protection.

05 / Native actions

Nested menu commands belong to this window. The unavailable workspace group disables all descendants. Tray availability depends on your desktop host; failures appear in the log.

06 / Application group

Each window uses these same assets and native callbacks. Quit asks every window first: if any has unsaved-change protection, the whole quit is cancelled. Check that window's log for the reason. Request acceptance alone does not mean a window closed.
