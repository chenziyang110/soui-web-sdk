## 目标与环境

Win7 RTM/SP1、Win8/8.1、Win10 各目标分支、Win11 和 WinPE 3.1/5/10/11 都列入环境盘点。具体支持以有身份的系统镜像、补丁及 x86/x64 验证结果为准。没有设备或镜像的项目保留未验证，不能借用本机结果。

固定场景：空白启动、10,000 行虚拟列表、中文表单、连续缩放、动画/图表、后台原生任务、三窗口切换、最小化/恢复、导航/重载/关闭。拟定 60 Hz 帧间隔 p95 ≤20 ms、超过 33.3 ms 的比例 ≤1%、输入到真实呈现 p95 ≤50 ms；高刷 120/144 Hz 单列。先采基线并冻结设备、负载与门槛，不因失败而放宽。

## 实施顺序

P01/P02/P04 建立真实可用的多后端基础；P03 与 P05 按证据优化。之后执行 P06—P10。现代运行时、旧内核维护、安全更新、签名与再分发审核分别记录。核心包按需选装模块；不把浏览器运行时体积从总成本中隐藏。
