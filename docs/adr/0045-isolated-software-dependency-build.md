# ADR0045：软件依赖构建与输出隔离

日期：2026-10-09。状态：实施，真实双架构构建待验证。关联 05-03、05-11。

默认兼容内核使用软件路径，实验 GPU 必须显式开启。依赖构建入口增加 `EnableExperimentalGpu`，只有开启时才编译 GPU 库并传入 GPU 链接参数；报告保留实际构建配置，构建成功不代表生产验收。

入口允许指定独立 `OutputRoot`，便于从新目录重建全部依赖和内核而保留历史产物。SOUI 的源暂存契约要求该目录位于 SDK 的 out 内；仅 Miniblink 可选择外部目录，这一约束在任何构建前检查。x86 工具链对应项目平台 Win32；原生辅助脚本明确区分工具链架构和项目平台。软件构建以非空内部参数 none 关闭 GPU，兼容 Windows PowerShell 5 的原生参数传递。资源编译输出放入 IntDir，避免将生成的 res 写回源目录。

本轮验证使用完整源码的隔离副本、全新中间和输出目录，按顺序重编 11 个核心静态库和全部内核翻译单元，不复用历史 obj/PCH/DLL 或实验 GPU 库。保留源码、工具、命令、输出与实际进程退出记录。第三方系统库、许可证、目标系统与长期资源验收仍单独核验。
